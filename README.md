## Vultr 还能买吗？先说清楚线路和被墙这两件事

所以判断不难下：

- 适合：海外业务部署、自用测试和学习、给海外访客建站、需要按小时弹性用机的场景

按小时计费把试错成本压得很低：开机后第一时间测 IP，不通就销毁重建，损失只是运行的那几个小时。
